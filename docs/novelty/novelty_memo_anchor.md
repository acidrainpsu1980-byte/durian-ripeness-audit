# Novelty assessment: intake-anchored batch calibration

## (a) Verdict

**The mechanism is not new; the way the anchor set is obtained in postharvest grading, and the evaluation built on it, can be claimed as new.** Adapting a trained multi-class model to a new domain with target data from **one known class only** has direct precedent. Machinery fault diagnosis has a whole line of "healthy-only target domain" work: [Li 2019](https://doi.org/10.1109/tie.2018.2868023) adapts a bearing classifier when only healthy-condition target data exist; [Wang 2021](https://doi.org/10.1109/tie.2019.2962438) aligns a target set that covers only a subset of classes onto the source class structure ("unilateral alignment") and names healthy-only target methods as its predecessors; [Rombach 2023](https://doi.org/10.1016/j.ress.2022.108857), [Ha 2023](https://doi.org/10.1016/j.ymssp.2023.110680) and [Liu 2025](https://doi.org/10.1049/icp.2025.2363) adapt with only normal-condition target data. In gas sensing, [Zhu 2021](https://doi.org/10.3390/chemosensors9080208) calibrates a drift-compensated classifier from "a single category of drift correction samples", and component correction [Artursson 2000](https://doi.org/10.1002/1099-128x%28200009/12%2914:5/6%3C711::aid-cem607%3E3.0.co%3B2-4) removes the drift direction estimated from a reference gas. Normalising each acquisition against a subset known to carry no signal of interest is also standard practice elsewhere: negative-control genes in RUV-2 [Gagnon-Bartsch 2011](https://doi.org/10.1093/biostatistics/kxr034), a reference tissue class in MRI intensity normalisation [Shinohara 2014](https://doi.org/10.1016/j.nicl.2014.08.008), impostor-cohort score normalisation in speaker verification [Auckenthaler 2000](https://doi.org/10.1006/dspr.1999.0360), and shared control samples per batch in CytoNorm [Gassen 2019](https://doi.org/10.1002/cyto.a.23904). All four proposed variants have close analogues. (i) Anchor-referenced standardisation is reference-class normalisation. (ii) BN re-estimation is AdaBN [Li 2018](https://doi.org/10.1016/j.patcog.2018.03.005) computed on a class-restricted subset. (iii) Logit/prior recalibration combines slope/bias correction [Bouveresse 1996](https://doi.org/10.1021/ac9510595) with known-class score normalisation. (iv) Single-class class-conditional alignment is what [Wang 2021](https://doi.org/10.1109/tie.2019.2962438) and [Liu 2025](https://doi.org/10.1049/icp.2025.2363) already do.

What I did **not** find, in fruit chemometrics, postharvest sensing or durian work, is any method that uses the harvest-day (intake) scans of a new batch as a class-known reference set. Those scans are labelled by the process at no extra cost. The fruit literature instead relies on three kinds of reference data: paired standards measured on both instruments (PDS, TOP, EPO); new-condition samples with destructive reference values (slope/bias correction, model updating [Capron 2005](https://doi.org/10.1016/j.chemolab.2004.11.003), semi-supervised PFCE per fruit batch [Mishra 2021](https://doi.org/10.1016/j.aca.2021.338771)); or fully unlabeled target spectra (di-PLS on fresh fruit [Mishra 2020](https://doi.org/10.1016/j.infrared.2020.103547), standard-free DOP [Mishra 2020](https://doi.org/10.1016/j.postharvbio.2020.111326), [Diaz 2022](https://doi.org/10.1016/j.aca.2022.340154)). The only durian work I found that addresses inter-season variation handles it by pooling two harvest years in training ("mixed-domain training"), not by adapting at test time [Nguyen 2026](https://doi.org/10.1016/j.rineng.2026.110709). This absence is a **provisional** finding. It rests mostly on abstracts, and it does not cover two 2026 COMPAG durian papers and two 2024 apple seasonal-transfer papers, for which only titles were retrievable.

The claim that COMPAG's scope would accept is therefore methodological and evaluative. The paper would show that a structural property of postharvest intake turns single-class target adaptation from a special assumption into a property of the protocol itself. It would then quantify, under leave-one-batch-out evaluation with concurrent label shift, how much anchoring adds over unanchored adaptation, and when the anchor's core assumption (a class-independent batch effect) fails. The paper must cite the fault-diagnosis and drift-correction precedents explicitly. A reviewer who knows either literature will otherwise read the method as a rediscovery.

## (c) Baselines the paper must report

Each baseline below shares the same leave-one-batch-out folds, the same frozen source models, and the same scoring set. Endpoint captures only are scored; see the design caveats below.

1. **No adaptation**: source model applied as is.
2. **Trivial capture-day rule**: predict Unripe for every intake capture, and apply the source model to endpoint captures. This is the floor that any anchored method must beat on the scored set. Without it, a reviewer can attribute the whole gain to process metadata.
3. **Unanchored per-batch feature standardisation** using all target captures (intake + endpoint), the per-domain whitening counterpart; cite [He 2020](https://doi.org/10.1109/tbme.2019.2913914) and the location/scale ComBat family [Johnson 2006](https://doi.org/10.1093/biostatistics/kxj037).
4. **Unanchored CORAL** on all target captures [Sun 2016](https://doi.org/10.1609/aaai.v30i1.10306) (Deep CORAL [Sun 2016](https://doi.org/10.1007/978-3-319-49409-8_35) if a trained-head variant is used).
5. **Unanchored AdaBN / prediction-time BN** for the knock CNN and EfficientNet branch [Li 2018](https://doi.org/10.1016/j.patcog.2018.03.005), [Schneider 2020](https://doi.org/10.48550/arxiv.2006.16971), [Nado 2020](https://doi.org/10.48550/arxiv.2006.10963).
6. **TENT** (optional, CNN branches) [Wang 2020](https://doi.org/10.48550/arxiv.2006.10726).
7. **Prior-shift EM** with bias-corrected temperature scaling [Saerens 2002](https://doi.org/10.1162/089976602753284446), [Alexandari 2019](https://doi.org/10.48550/arxiv.1901.06852); BBSE as a secondary estimator [Lipton 2018](https://doi.org/10.48550/arxiv.1802.03916). This isolates how much of the failure is label shift and how much is covariate shift.
8. **Anchor-only bias correction** (intercept shift of features or logits estimated from anchors), the classification analogue of slope/bias correction [Bouveresse 1996](https://doi.org/10.1021/ac9510595). Report it separately from the full anchor-referenced standardisation (location + scale). Note in the text that classical slope/bias correction requires reference values; the anchor version needs only class identity.
9. **Single-class alignment from the fault-diagnosis literature**, the most direct prior-art comparator. At minimum, implement a lightweight version of unilateral/class-conditional alignment of target anchors to the source Unripe class [Wang 2021](https://doi.org/10.1109/tie.2019.2962438), [Liu 2025](https://doi.org/10.1049/icp.2025.2363). If this is infeasible at n ≈ 55 anchors per batch, state that and explain why.
10. **Chemometric unsupervised adaptation for the NIR branch**: di-PLS or unsupervised DOP [Nikzad-Langerodi 2018](https://doi.org/10.1021/acs.analchem.8b00498), [Diaz 2022](https://doi.org/10.1016/j.aca.2022.340154), [Mishra 2020](https://doi.org/10.1016/j.infrared.2020.103547).
11. **Labelled-target upper bound**: few labelled target fruit per class, via model updating [Capron 2005](https://doi.org/10.1016/j.chemolab.2004.11.003), [Mishra 2021](https://doi.org/10.1016/j.aca.2021.338771) or semi-supervised DA [Saito 2019](https://doi.org/10.1109/iccv.2019.00814). This shows how much of the labelled-adaptation gap the free anchors close.
12. **Pooled-batch (mixed-domain) training reference** with random-batch CV, as in [Nguyen 2026](https://doi.org/10.1016/j.rineng.2026.110709) and [Anderson 2020](https://doi.org/10.1016/j.postharvbio.2020.111202). It is not a fair LOBO competitor, but it shows the in-distribution ceiling.

## (d) Claim wording

**Suggested defensible claim (one sentence).** "Because every fruit is scanned on its harvest day, the intake captures of a new batch form a process-labelled, single-class reference set at no labelling cost; we show how much this known-class anchor, an instance of single-class target adaptation previously used in machinery fault diagnosis and gas-sensor drift correction, recovers leave-one-batch-out ripeness classification across acoustic, thermal, RGB and NIR sensing relative to unanchored adaptation."

**Wording that would overclaim and must be avoided:**
- "A novel domain adaptation / test-time adaptation method", or "we propose anchor-based adaptation". The mechanism exists (rows 1–7, 11–12).
- "The first use of known-class samples for calibration transfer / domain adaptation". This is contradicted by rows 1–7.
- "Label-free" or "unsupervised" adaptation. The anchors carry class information; say "without additional labels" or "using only process-known labels".
- "The first work to address batch or season shift in durian". [Nguyen 2026](https://doi.org/10.1016/j.rineng.2026.110709) addresses inter-annual variation, by pooling. "First to evaluate test-time adaptation for durian ripeness" is defensible only as "to our knowledge", and only after the two 2026 COMPAG durian papers have been read.
- "Solves" or "eliminates" batch shift. With three batches and 164 fruit, the evidence is three LOBO folds.
- Calling the anchors "calibration standards" or "transfer samples". In chemometrics those terms mean paired samples measured on both instruments; the anchors are different fruit of a known class.

## Design caveats

These follow from the prior art and affect whether the claim survives review.

1. **Scoring set and label leakage.** If every Unripe capture in the dataset is an intake capture, the anchor set *is* the target Unripe class. Accuracy on intake captures then becomes trivially high once intake status is known. The honest evaluation scores endpoint captures only, which is probably a Ripe-vs-Overripe problem (plus any endpoint Unripe fruit). The paper must state this, report the class composition of endpoint captures per batch, and include baseline 2.
2. **Class-independent shift assumption.** The anchors identify a batch transform only if that transform is the same for Unripe and for Ripe/Overripe fruit (location–scale conditional shift shared across classes). This assumption is plausible for camera model and thermal quantisation. It is less plausible for ambient temperature, which may interact with the respiration heat of ripening fruit. Because LOBO gives target labels for evaluation, report the per-class shift (e.g. batch mean offsets per class and modality) as a diagnostic of when anchoring should and should not work.
3. **Intake-day versus endpoint-day conditions.** Anchors are acquired on harvest day, but endpoint captures are taken days later, possibly at a different ambient temperature. Anchoring corrects batch-constant factors (camera, export quantisation) but not condition differences between intake and endpoint days within a batch. Analyse the acquisition metadata (date and temperature of each capture) before experiments.
4. **Estimator variance.** With about 55 anchors per batch, full covariance alignment of a 1280-d embedding is ill-posed. Pre-register diagonal (mean/variance) standardisation, or shrinkage, for the high-dimensional branches.
5. **Per-fruit longitudinal referencing** (endpoint minus own intake) is a different idea from batch-level anchoring. It is paired within fruit, closer to the shared-control logic of [Gassen 2019](https://doi.org/10.1002/cyto.a.23904), and requires fruit identity at grading time. If it is used, present it as a separate arm, not as part of the anchor method.

## Search scope and limits

The sweep covered roughly 110 OpenAlex relevance-ranked queries across the four categories, targeted Crossref resolution of landmark papers, arXiv API queries for known-class/test-time adaptation, and one citation-trail step from the unilateral-alignment paper, whose related-work section led to the healthy-only fault-diagnosis line. Of the 69 works in the CSV, one was read in full, 57 were judged from abstracts (or Semantic Scholar TLDRs where flagged), and 11 from metadata only. Presence/absence statements ("no fruit work uses intake anchors") are therefore provisional. The highest-value follow-up reads are the two 2026 COMPAG durian papers ([Orkweha 2026](https://doi.org/10.1016/j.compag.2026.112227), [Jing 2026](https://doi.org/10.1016/j.compag.2026.112582)), the apple seasonal-transfer papers ([Pan 2024](https://doi.org/10.1016/j.jfca.2024.106028), [Pan 2024](https://doi.org/10.1016/j.biosystemseng.2024.07.010)), the e-nose one-class paper [Zhu 2021](https://doi.org/10.3390/chemosensors9080208) (to see whether its single-category samples are the same class as the target anchors), and [Zanini 2018](https://doi.org/10.1109/tbme.2017.2742541) (to see which trials define the reference covariance).
